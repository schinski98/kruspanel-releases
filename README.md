# KrusPanel

KrusPanel turns an old tablet or phone on your home network into a control panel for your
Windows PC: buttons run actions, data fields show live values.

This repository only hosts the installers. Download the latest `KrusPanel-Setup-*.exe` from
[Releases](https://github.com/schinski98/kruspanel-releases/releases/latest).

## Install

1. Download and run the installer. It is not code-signed yet, so Windows SmartScreen warns:
   click **More info → Run anyway**.
2. KrusPanel opens its configuration window and guides you through the setup.
3. Scan the QR code with your tablet or phone and add the page to the home screen.

Requirements: Windows 10 or 11, tablet or phone in the same home network.
